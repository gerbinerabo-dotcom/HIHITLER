# Personal Life Manager

Telegram-бот для задач, личных финансов и привычек. Данные хранятся локально в SQLite и привязаны к Telegram ID пользователя.

Нужен Node.js 20 или новее.

## Запуск в Windows PowerShell

```powershell
cd C:\Users\EsenovE\Desktop\ytuh\life_manager_bot
npm install
Copy-Item .env.example .env
notepad .env
npm run dev
```

Создайте бота через @BotFather и укажите токен в `BOT_TOKEN` файла `.env`. База данных создаётся автоматически.

При первом запуске пользователь выбирает русский, қазақша, кыргызча, English, français или Deutsch. Валюта выбирается отдельно; суммы не конвертируются. Чтобы получать идеи пользователей в Telegram, укажите свой Telegram ID в `SUPPORT_ADMIN_IDS` (можно несколько ID через запятую). Команда `/feedback` показывает последние обращения администраторам.

## Как вводить данные

- Задача: `Английский завтра 18:00`, `Английский 24.10.2026 18:00` или только `Прочитать книгу` (на сегодня). Если отправить только дату, бот отдельно попросит название. Можно отметить выполнение или перенести на завтра.
- Доход или расход: отправьте сумму и выберите категорию и свой счёт. Можно также одной строкой: `40000 | Зарплата | Halyk`.
- Счёт: создайте его в разделе «Финансы», указав своё название и начальный баланс, например `Halyk | 0`.
- Перевод: `5000 | Halyk | Наличные`. Переводы не включаются в отчёт доходов и расходов.
- Привычка: цель по умолчанию — 90 выполнений. Пропуски не сбрасывают прогресс; статистика показывает общий прогресс и записанные минуты занятий.
- В настройках можно включать и выключать разделы, менять язык и валюту, настраивать напоминания, экспортировать JSON или удалить данные.
- Кнопка «Техподдержка» сохраняет идеи; при настроенном `SUPPORT_ADMIN_IDS` бот также уведомляет команду.

Команды: `/start`, `/menu`, `/help`, `/cancel`.
